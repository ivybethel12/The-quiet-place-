THE QUIET PLACE — Prototype v2

Open index.html in a browser.

Included:
- Responsive Christian community homepage
- Anonymous post composer
- Random public anonymous identities
- Categories and category filtering
- Latest/popular sorting
- Like buttons
- Local browser storage for posts
- Prayer-request entry point
- Report placeholder
- Privacy/community messaging

This is still a front-end prototype. The next production step is a secure backend/database (for example PostgreSQL/Supabase), real authentication/session handling, server-side validation, moderation, rate limiting, reporting workflows, and a privacy policy.
